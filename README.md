# 🎓 SnapClass – AI-Powered Smart Attendance System

## 📌 About the Project

SnapClass is an AI-powered smart attendance management system designed to make attendance management more efficient and intelligent.

## ✨ Key Features

- 👨‍🎓 Student Portal
- 👨‍🏫 Teacher Portal
- 📷 Face Recognition-Based Identification
- 🎙️ Voice Enrollment Support
- 📚 Subject Enrollment and Management
- 📊 Attendance Tracking
- 🔐 Supabase Database Integration
